# ASHA profile assets

The profile uses original ASHA artwork, self-contained SVG assets, and a single automatically refreshed statistics card.

| File | Purpose |
| --- | --- |
| `asha-v2-banner.svg` | Current 1200 × 360 ASHA banner with cream background and pastel accents |
| `asha-mark.svg` | Earlier compact ASHA portrait, retained as an available asset |
| `asha-banner.svg` | Earlier 1200 × 320 cream and pastel banner, retained as an available asset |
| `pastel-divider.svg` | Earlier pastel pixel divider, retained as an available asset |
| `github-stats.svg` | Public GitHub statistics, generated every six hours |

## Palette

Cream `#FFF9F5` and white `#FFFFFF` cover most of the artwork. Cream pink `#F3CED9`, mint `#D6EDE5`, and sky `#D8E8F6` provide balanced accents. Lilac `#E5DEF3` is used sparingly. Text uses charcoal `#393741`, warm gray `#625D66`, and muted gray `#79727D`.

## ASHA illustration

ASHA is an original young-adult female developer mascot. The v2 artwork follows the selected character model sheet: cream-pink layered long hair, gentle gray-violet eyes, a calm expression, a translucent forehead XR visor, and an ivory technical jacket with sky and mint accents. The banner keeps ASHA on the right and developer-focused wording on the left.

The banner embeds the finished illustration directly as a PNG inside a self-contained SVG. It needs no external image host. Its cream background and charcoal lettering keep the image readable in both GitHub themes. The introduction, timeline, and technology stack use ordinary Markdown for readability on phones. The README pins the banner to its asset commit so a previous cached image cannot replace the intended version.

The README prioritizes the user's introduction, timeline, and technology stack. Projects provide brief supporting context. The automatically updated statistics card is displayed at a compact width of 420 pixels inside a collapsible section.
